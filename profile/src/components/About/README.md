Components trong thư mục này dùng cho trang `About` để bạn dễ “design như git commit”.

- `GitCommitTimeline`: list commit, click để expand
- `GitCommitRow`: dòng commit rút gọn (chỉ hiện commit)
- `GitCommitDetails`: phần thông tin chi tiết khi expand
- `GitCommitCard`: (legacy) card commit cũ, hiện không dùng
- `AboutPanel`: panel wrapper tái sử dụng cho các section khác
